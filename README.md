# B-Spline Simulator
 
Interactive B-Spline Curve and Surface Simulator written in C++ and OpenGL.
 
## Features
- B-Spline Curve Evaluation
- Cox-De Boor Basis Function
- Control Polygon Visualization
- Camera Orbit / Zoom
- OpenGL Rendering
